# Conseils amélioration site MGC

Site déjà bien : multi-pages, version EN, sitemap, robots, 404, mentions légales, favicon, og-image, newsletter, compteur menaces.

## Priorité haute
1. **Contact** : formulaire contact (nom, email, message) + bouton "Demander un audit" bien visible sur chaque page. Pas de conversion = pas de clients.
2. **Preuves de confiance** : logos clients (si accord), certifications (ISO 27001, PASSI, etc.), chiffres (nb missions, années), témoignages.
3. **Texte** : relire toutes les pages (fautes, ton homogène). Ex. page cybersécurité corrigée.
4. **Mobile** : tester sur téléphone (menu, boutons, tailles texte).
5. **RGPD** : bandeau cookies si analytics, mention newsletter (consentement + désinscription), politique de confidentialité.

## SEO
- Pages FR/EN : balises `hreflang` entre versions.
- Une `meta description` unique par page (vérifier toutes).
- Balises `alt` sur toutes les images (équipe, etc.).
- Données structurées `schema.org` (Organization, LocalBusiness).
- Google Search Console : envoyer `sitemap.xml`.
- Google Business Profile (Paris).

## Technique
- Compresser images (WebP), `loading="lazy"`.
- Minifier `styles.css` (46 Ko).
- HTTPS + en-têtes sécurité (CSP, HSTS, X-Frame-Options) — logique pour un site cybersécurité.
- Tester Lighthouse (perf, accessibilité, SEO) : viser 90+.
- Accessibilité : contraste, navigation clavier, labels formulaires.

## Contenu
- Blog / actualités menaces (renforce SEO + crédibilité).
- Pages cas d'usage / études de cas anonymisées.
- FAQ par service.
- Page "À propos / équipe" détaillée (photos déjà présentes).
- Lead magnet : guide PDF "10 bonnes pratiques cyber" contre email.

## Ordre conseillé
1. Formulaire contact + CTA
2. Preuves confiance
3. SEO de base (meta, hreflang, alt)
4. Perf images
5. Blog
